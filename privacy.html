隱私權政策

Privacy Policy · 最後更新 2026-10-23

適用範圍

本政策適用於開發者 developergxc 在自己電腦上執行、透過 Google OAuth 存取開發者本人 Google 帳號的個人自動化工具。這些工具只供開發者本人使用。

取得哪些資料

  • Gmail：以唯讀權限讀取開發者本人的信件與附件
  • YouTube：讀取開發者本人頻道的影片與直播資訊，必要時更新自己影片的標題或說明

如何使用與保存

  • 資料只在開發者自己的電腦上處理與保存，用來整理開發者本人的紀錄
  • 不出售、不出租、不分享給任何第三方，也不用於廣告
  • OAuth 憑證只存放在開發者自己的電腦上

本工具使用 Google API 取得的資料，遵守 Google API 服務使用者資料政策，包括「有限使用」（Limited Use）要求。

撤銷授權

可隨時到 Google 帳戶的第三方存取權頁面 移除授權，移除後工具就無法再存取帳號資料。

English summary

These tools are used only by the developer, on the developer's own computer, to access the developer's own Google account data (Gmail read-only and the developer's own YouTube channel). Data is processed and stored locally, never sold or shared with third parties, and never used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
